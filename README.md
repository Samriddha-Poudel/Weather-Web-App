# Weather.io
This is a simple Weather web app which is made by using HTML, CSS ans Java Script . I have used Weather API through Rapid API. This Web app calls the Weather API to get the information and display
it to the user.

## Technologies Used:
- HTML: HTML is used in this project to add the HTML elements and to provide the basic structure of the Web App.
- CSS: CSS is used in this project to style the HTML elements and icons etc and make the page look interactive .
- JS: JS is used in this project to call the API and get the data .
